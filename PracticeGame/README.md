
## Modules

### Config
Contains all project settings.

### MathUtils
Contains reusable math functions.

### PlayerCache
Stores player data and improves performance.

### UIController
Controls interface visibility and animations.

### DragController
Handles draggable UI windows.

### CameraController
Controls camera systems.

## Development Tools

- Visual Studio Code
- Roblox Studio
- Rojo
- Luau Language Server
- StyLua
- Selene

## Setup

1. Open the project folder in VS Code.
2. Start Rojo.
3. Connect the project to Roblox Studio.
4. Run the game.
